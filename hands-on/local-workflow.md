# 🧪 Local Git Workflow

```bash
git init
git add .
git commit -m "Initial commit"
git log

### Git Basics: Using snapshot logic 

| Command | Action | Technical Meaning | Simple Analogy |
| :--- | :--- | :--- | :--- |
| `git init` | **Initialize** | Creates a hidden `.git` folder in your directory. | **Setting up the Studio:** Tells Git to start watching. |
| `git add .` | **Stage** | Moves all current changes into the "waiting room." | **Framing the Shot:** Getting everyone ready for the photo. |
| `git commit -m "..."` | **Commit** | Saves the staged snapshot to the project history. | **Taking the Photo:** Permanently saving the moment. |
| `git log` | **History** | Lists every commit made in the project. | **Reviewing the Album:** Looking back at the timeline. |

You’ve just created your first Git repo
