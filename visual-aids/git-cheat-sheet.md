# 🧾 Git Cheat Sheet

| Action         | Command                      |
|----------------|------------------------------|
| Init repo      | `git init`                   |
| Add files      | `git add .`                  |
| Commit         | `git commit -m "message"`    |
| View history   | `git log`                    |
| Branch         | `git checkout -b feature`    |
| Merge          | `git merge feature`          |
| Push to GitHub | `git push origin main`       |
